# content/pipeline/active

Only in-progress posts belong here.

Each post should usually contain:
- `brief.md`
- `status.json`
- `draft.md`
- `notes.md`
- `socials.md` optional

Once a post is published, either:
- remove its folder from `active/`, or
- move it into `archive/<year>/<slug>/` if you want to preserve workflow history
